# Pet Care

PawClean 宠物洗护展示与预约页面，使用 Next.js 迁移自原静态页面。

## 技术栈

- Next.js App Router
- React
- TypeScript
- Global CSS

## 本地运行

```bash
npm.cmd install
npm.cmd run dev
```

打开 `http://localhost:3000` 查看页面。

## 构建与生产运行

```bash
npm.cmd run build
npm.cmd run start -- -p 3000
```

## 主要功能

- 宠物洗护服务展示
- 门店环境轮播
- 护理师选择
- 预约表单
- 根据宠物类型和服务项目自动预估价格
